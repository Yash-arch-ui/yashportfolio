# Yash Singh — Portfolio

Personal portfolio of **Yash Singh** — sophomore at IIT Roorkee, building DeFi
infrastructure across Uniswap V4, Morpho Blue, Balancer V3, Zama FHEVM and Sui.

**Live focus areas:** AMM design · liquidation systems · dynamic fee mechanisms · confidential assets

## Featured work

| Project | What it is |
| --- | --- |
| **WrapLayer** | Interface for Zama's on-chain Wrappers Registry — discover, shield and transfer canonical ERC-20 ↔ ERC-7984 confidential asset pairs on FHEVM |
| **Morpho Liquidation Bot** | Open-source contribution: RPC-only, multi-chain liquidation bot for Morpho Blue with pluggable pricers and liquidity venues |
| **HookShield** | Dynamic fee hook for Uniswap V4 — adaptive swap pricing from external market data via BeforeSwap/AfterSwap |
| **Aegis AMM** | Circuit-breaker AMM on Sui (Move) that halts trading when EMA-based risk thresholds trip, protecting LPs from flash crashes |
| **Balancer V3 Router** | 🚧 In progress — extending Balancer V3's swap-routing layer |
